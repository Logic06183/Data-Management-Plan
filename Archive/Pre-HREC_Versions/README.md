# Archive: Pre-HREC Versions (Never Submitted)

This directory contains all version 2.x documents that were developed but **never submitted to HREC for ethics approval**.

## Important Context

- **Version 1.0**: Successfully submitted and approved by HREC
- **Versions 2.0-2.2**: Developed internally but never submitted to HREC
- **Current Submission**: All changes consolidated into Version 2.0 HREC submission

## Repository Reorganization (September 2025)

**Problem Identified**: Multiple version increments (2.0 → 2.1 → 2.2) were developed but never submitted to HREC, creating a compliance gap.

**Solution Implemented**: Consolidate all changes from versions 2.0-2.2 into a single Version 2.0 HREC submission, presenting this as one comprehensive update from the approved Version 1.0.

**New Approach**: 
- Archive all never-submitted versions in this directory
- Create unified Version 2.0 HREC submission in `/Version_2.0_HREC_Submission/`
- Present thematically organized changes rather than chronological versions
- Maintain complete audit trail while streamlining HREC review process
