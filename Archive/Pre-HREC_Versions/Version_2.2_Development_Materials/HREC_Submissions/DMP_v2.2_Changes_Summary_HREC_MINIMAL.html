NATURE OF AMENDMENT: Implementation of cloud migration infrastructure and establishment of transition framework for Year 5. This amendment introduces WHC-managed cloud infrastructure alongside existing UCT systems, establishes enhanced security measures, implements universal Data Access Committee (DAC) review requirements, and creates a structured transition plan. All existing ethical safeguards are maintained and significantly enhanced.

PARTICIPANT IMPACT: No direct impact on participants.

RISK ASSESSMENT: Risk significantly reduced through enhanced security measures including AES-256 encryption, 24/7 SOC monitoring, advanced threat detection, automated backup systems with geographic redundancy, and dual infrastructure capability during transition period ensuring continuity of operations.

ETHICAL IMPACT ASSESSMENT

Participant Rights: All existing participant rights maintained and significantly enhanced through implementation of dual infrastructure with enhanced security measures during transition period.

Data Protection: Substantial enhancement achieved through:

  • AES-256 encryption standard for all data in transit and at rest

  • 24/7 Security Operations Centre (SOC) monitoring with advanced threat detection

  • Dual infrastructure capability ensuring continuity during transition

  • Automated backup systems with geographic redundancy

  • Enhanced disaster recovery capabilities

  • Cloud-native firewall services alongside existing security measures

Consent and Transparency: Maintained provider consent framework with enhanced communication template. Systematic approach to data provider notification regarding transition. All migrations require explicit provider agreement.

Governance Enhancement: Universal DAC review requirement implemented for ALL projects including internal consortium members. No exceptions to comprehensive data access review process. Enhanced audit trails and compliance reporting.

Risk Mitigation: Transition approach significantly reduces operational risks through:

  • Systematic 5-phase migration strategy with validation at each stage

  • Dual infrastructure capability ensuring service continuity

  • Enhanced professional-grade security monitoring

  • Automated compliance reporting and audit capabilities

  • Geographic redundancy and improved disaster recovery

CONFIRMATION

These amendments document the implementation of cloud migration infrastructure and establishment of systematic transition framework for Year 5. The transition maintains enhanced data protection through dual infrastructure capability, significantly strengthened security measures, and systematic migration approach. All existing ethical safeguards are maintained and substantially enhanced. No changes to research methodology, participant recruitment, or data collection procedures.

The universal DAC review requirement has been implemented to ensure equitable and transparent data governance for ALL users, including internal consortium members, with no exceptions.

All changes maintain full POPIA compliance and enhance alignment with international data protection standards through professional-grade security measures and comprehensive audit capabilities.
