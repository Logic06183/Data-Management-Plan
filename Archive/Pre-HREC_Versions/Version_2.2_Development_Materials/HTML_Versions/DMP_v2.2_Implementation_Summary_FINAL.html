Key Changes Implemented by Category

1. Cloud Infrastructure Transition Updates

Primary Change: Complete removal of transitional language and establishment of WHC-managed cloud infrastructure as the primary platform.

Sections Updated:

  • Section 4.1.2 (Original Study Data): Implemented single copy policy on cloud infrastructure per LA3 comment. Removed dual storage references.
  • Section 4.2 (Climate/Weather Data): Removed transition period language and auto-scaling references.
  • Section 6.1 (Pre-processing): Updated to reflect WHC-managed cloud infrastructure with enhanced security.
  • Section 8 (Data Analysis Platform): Removed transition period references, established cloud-based computational resources.
  • Section 14 (Restricted Data Access): Updated encryption standards to AES-256 across all infrastructure.

2. Data Access Committee (DAC) Role Clarifications

Major Policy Change: DAC now evaluates ALL data access requests, both internal consortium members and external researchers.

Key Implementations:

  • Section 10.4: Updated to specify "All projects, regardless of whether they involve internal HE²AT Center Consortium members or external researchers, must go through the DAC for data access approval."
  • Section 12.3: Clarified that DAC evaluates ALL data access requests with consistent ethical and scientific standards.
  • Enhanced Governance: Ensures equitable data sharing and comprehensive tracking of all projects.

3. Contact Information Standardization

Professional Contact Management: Replaced individual names with institutional contacts for improved document maintenance.

Changes Made:

  • Generic Contact Updates: Replaced "Elizabeth Frederick" with "HE²AT Data Management Team"
  • Email Standardization: Updated to data.management@he2at.org
  • Section 15 Updates: Removed individual names from roles and responsibilities table

4. Document Structure Optimization

Streamlined Architecture: Removed completed transition documentation and renumbered annexes for clarity.

Structural Changes:

  • Annex 1 (Transition Implementation Details): Removed - no longer needed with completed migration
  • Annex Renumbering: Key data sources (now Annex 2), POPIA agreements (now Annex 3), Ethics templates (now Annex 4), DAC Terms (now Annex 5), Data Request Form (now Annex 6)
  • Cover Page Cleanup: Removed duplicated version numbering

Technical Infrastructure Updates

Security Enhancements Implemented

  • Encryption Standards: AES-256 encryption implemented across all infrastructure components
  • 24/7 Monitoring: WHC-managed Security Operations Centre (SOC) monitoring established
  • Advanced Threat Detection: Automated threat detection systems implemented
  • Enhanced Backup Systems: Automated backup and disaster recovery capabilities
  • Network Security: Updated network security protocols for cloud infrastructure

Data Transfer Protocol Updates

  • WeTransfer: Removed as data transfer option
  • FileSender: Established as primary secure data transfer protocol
  • Encryption in Transit: All data transfers encrypted during transmission
  • Storage Encryption: AES-256 encryption for all stored data

Compliance and Governance Enhancements

Universal DAC Review Implementation

Policy Enhancement: The most significant governance change is the establishment of universal DAC review for ALL data access requests. This ensures:

  • Equitable treatment of internal consortium members and external researchers
  • Consistent application of ethical and scientific standards
  • Comprehensive tracking and oversight of all data usage
  • Enhanced transparency in data governance decisions

POPIA Compliance Maintenance

  • Enhanced Data Protection: Single copy policy for sensitive data reduces exposure risk
  • Improved Access Controls: Role-based access control system implementation
  • Automated Compliance Reporting: Cloud infrastructure provides enhanced audit capabilities
  • Professional Monitoring: 24/7 SOC monitoring ensures continuous compliance oversight
