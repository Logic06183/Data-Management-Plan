Data Management Plan Version 2.2 - Summary of Proposed Changes

Study Title: Heat and Health in Africa Transdisciplinary Center Data Management Plan

Protocol number: HE²AT-DMP-v2.2

Date of last version of protocol: 09 September 2024

HREC Reference No: RP1-220605 and RP2-220606

Overall Rationale for the Amendment

The HE²AT Center Data Management Plan Version 2.2 implements a transition from UCT on-premise infrastructure to WHC-managed cloud infrastructure during Year 5 to enhance data security, scalability, and operational efficiency whilst maintaining full regulatory compliance.

Key changes include:

  • WHC-managed cloud infrastructure with AES-256 encryption
  • 24/7 Security Operations Centre monitoring and advanced threat detection
  • Automated backup and disaster recovery systems
  • Cloud-based computational resources with GPU acceleration
  • Structured 5-phase migration strategy with comprehensive risk mitigation

POPIA Compliance

All enhanced data management procedures maintain full POPIA compliance:

  • Data stored on secure cloud servers with appropriate cross-border transfer protections
  • Only the research team will have access to participant data through enhanced authentication protocols
  • Data will continue to be anonymized using participant IDs
  • All cloud infrastructure changes enhance existing compliance standards

Implementation

Upon receiving research ethics committee approval, the cloud migration will be implemented following a structured 5-phase approach during Year 5. All changes enhance rather than compromise participant protection through improved technical infrastructure.
