# Archive: Version 2.2 Development Files

This directory contains all working documents, drafts, and intermediate files that were created during the development and review process of DMP Version 2.2. These files have been archived to maintain a clean root directory structure while preserving the complete audit trail of the document development process.

## Archive Date
September 5, 2025

## Directory Structure

### `/Diagrams/`
Contains all SVG diagram files that were part of the v2.2 development process:
- `HE2AT_Cloud_Migration_Transition.svg` - Cloud migration visualization
- `HE2AT_Data_Flow_British_v2.2.svg` - Data flow with British spelling conventions
- `HE2AT_Data_Flow_Pipeline.svg` - Data processing workflow diagram
- `HE2AT_Data_Flow_Updated_v2.2.svg` - Updated data flow visualization
- `HE2AT_Data_Management_Architecture.svg` - Comprehensive system architecture diagram

### `/HTML_Versions/`
Contains HTML versions of documents created during the review and implementation process:
- `DMP_v2.2_Implementation_Summary_FINAL.html` - Final implementation summary in HTML format
- `HE2AT_DMP_v2.2_base.html` - Base HTML version of the DMP
- `HE2AT_DMP_v2.2_tracked_changes.html` - HTML version with tracked changes

### `/Instructions_and_Tracking/`
Contains all markdown files with instructions, tracking documents, and implementation guides:
- `DMP_v2.2_Tracked_Changes_Instructions.md` - Instructions for implementing tracked changes
- `HE2AT_DMP_v2.2_TRACKED_CHANGES_IMPLEMENTATION_GUIDE.md` - Comprehensive implementation guide
- `HE2AT_DMP_v2.2_TRACKED_CHANGES_IMPLEMENTED.md` - Documentation of implemented changes
- `HE2AT_DMP_v2.2_WITH_TRACKED_CHANGES.md` - Markdown version with tracked changes
- `TRACKED_CHANGES_IMPLEMENTATION_SUMMARY.md` - Summary of all tracked changes implemented

### `/Working_Documents/`
Contains working files and extracted media used during document preparation:
- `extracted_media/` - Directory containing media files extracted from documents
  - `media/image2.emf` - EMF format image
  - `media/image3.png` - PNG format image
  - `media/image4.jpeg` - JPEG format image
  - `media/image5.jpeg` - JPEG format image
- `figure1_base64.txt` - Base64 encoded figure data

## Purpose of Archive

This archive preserves the complete development history of DMP Version 2.2, including:
1. **Version Control**: All intermediate versions and working documents
2. **Implementation Tracking**: Detailed records of changes made during the review process
3. **Media Assets**: All extracted images and diagrams used in document preparation
4. **Review Process**: HTML versions created for stakeholder review
5. **Technical Documentation**: Implementation guides and instructions

## Relationship to Main Documents

The files in this archive support and document the creation of the final documents that remain in the repository root:
- `HE2AT_DMP_v2.2_COMPLETE_with_figures_22082025.docx`
- `HE2AT_DMP_v2.2_WITH_TRACKED_CHANGES_IMPLEMENTED.docx`

## Access and Usage

These archived files should be referenced when:
- Understanding the development process of DMP v2.2
- Reviewing specific changes made during the cloud migration update
- Accessing working versions of diagrams and visualizations
- Auditing the document development and review process
- Troubleshooting issues with the final documents

## Archive Maintenance

This archive represents a snapshot of the working files as of the repository reorganization on September 5, 2025. Future development work on subsequent DMP versions should create new archive directories following the same organizational structure.
