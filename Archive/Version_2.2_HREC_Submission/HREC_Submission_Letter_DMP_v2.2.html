Overall Rationale for the Amendment

The Heat and Health in Africa Transdisciplinary (HE²AT) Center aims to advance climate-health research in Africa through enhanced data management infrastructure while protecting participant privacy. We respectfully submit this amendment notification for the transition from Version 2.1 to Version 2.2 of our Data Management Plan, which introduces cloud migration and enhanced security infrastructure.

The primary rationale for this amendment is the implementation of a structured cloud migration strategy to enhance data management capabilities while maintaining operational continuity. This transition from UCT-only infrastructure to WHC-managed cloud infrastructure provides enhanced security, scalability, and operational efficiency whilst maintaining full regulatory compliance. The key changes include:

  • Introduction of WHC-managed cloud infrastructure with AES-256 encryption and 24/7 Security Operations Centre monitoring
  • Implementation of a structured 5-phase cloud migration strategy with comprehensive risk mitigation
  • Data custodian transition from UCT to WHC with tripartite agreement requirements and Data Provider consent procedures
  • Addition of human subjects study classification requirements and enhanced participant protection measures
  • New sections addressing cloud migration implementation, data sharing agreement alignment, and post-project data management
  • Enhanced authentication and authorization protocols with cloud-specific access controls
  • Interim data access restrictions during the transition period to ensure compliance

Implementation of the Protocol Modification

Upon receiving research ethics committee approval for this protocol amendment, the cloud migration will be implemented following the structured 5-phase approach outlined in the updated plan. The migration includes comprehensive planning, pilot implementation, gradual migration, full migration, and optimization phases with explicit migration deadline of June 2026.

A copy of the protocol amendment approval along with any correspondence will be retained in the Center's regulatory files. All Data Providers will be formally notified regarding the custodian role transition with 90-day advance notice and explicit consent requirements before any data transfer to WHC-managed infrastructure.

Enhanced Security and Participant Protection

Version 2.2 introduces significant enhancements to participant data protection through advanced cloud security infrastructure. The WHC-managed cloud environment provides AES-256 encryption for all data at rest and in transit, zero-trust network architecture implementation, advanced threat detection and monitoring systems, and automated security compliance reporting.

The human subjects study classification introduces additional legal and ethical requirements including enhanced informed consent procedures, strengthened participant rights protection, additional documentation requirements, and expanded data subject notification obligations.

Data Provider Rights and Consent Framework

The amendment establishes comprehensive procedures for Data Provider consent regarding cloud migration. Data Providers who consent to cloud migration will benefit from enhanced security and accessibility, while those who refuse will have their data maintained under existing UCT custodianship arrangements. This dual infrastructure approach ensures no penalties for Data Providers who prefer to maintain existing arrangements.

POPIA Compliance

According to the rules of the Protection of Personal Information Act 4 of 2013 (as amended), all enhanced data management procedures maintain full POPIA compliance. Data collected through cloud systems will be stored on secure servers which may be hosted outside of South Africa, with appropriate cross-border transfer protections. Only the research team will have access to data through enhanced authentication and authorization protocols. Data will continue to be anonymized using participant IDs with strengthened de-identification protocols.

Committee Assurance

On behalf of the HE²AT Center research team, I provide the following assurances to the Committee:

  • Enhanced rather than compromised participant data protection through advanced cloud security infrastructure
  • All existing ethical approvals and conditions remain fully applicable with additional protections
  • No changes to research methodology, participant recruitment, or data collection procedures
  • Comprehensive consent procedures for all Data Providers regarding cloud migration
  • Maintained dual infrastructure for Data Providers who prefer existing arrangements
  • Regular progress reports will be provided to the Committee throughout the migration process
  • Any unforeseen issues will be immediately reported to the Committee
