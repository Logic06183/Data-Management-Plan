Overall Rationale for the Amendment

The HE²AT Center Data Management Plan Version 2.2 represents a significant enhancement to our data management infrastructure through the implementation of cloud migration and advanced security measures. This amendment transitions from Version 2.1 (UCT-only infrastructure) to Version 2.2 (hybrid UCT and WHC-managed cloud infrastructure) to provide enhanced security, scalability, and operational efficiency whilst maintaining full regulatory compliance.

Key changes documented in this amendment include:

  • Introduction of WHC-managed cloud infrastructure with AES-256 encryption replacing UCT-only infrastructure
  • Implementation of structured 5-phase cloud migration strategy during Year 5 with complete health data migration deadline
  • Enhanced security architecture including 24/7 Security Operations Centre monitoring and advanced threat detection
  • Cloud-based computational resources with GPU acceleration for improved analytical capabilities
  • Automated backup and recovery systems with enhanced data integrity and disaster recovery
  • Cloud-specific access controls and automated compliance reporting for streamlined governance oversight
  • Comprehensive transition implementation framework with detailed communication procedures for data providers
Implementation of the Protocol Modification

Upon receiving research ethics committee approval for this protocol amendment, the cloud migration will be implemented following a structured 5-phase approach during Year 5 of the project. The transition from UCT on-premise infrastructure to WHC-managed cloud infrastructure will enhance security, scalability, and operational efficiency whilst maintaining full regulatory compliance. A copy of the protocol amendment approval along with any correspondence will be retained in the Center's regulatory files.

POPIA Compliance

According to the rules of the Protection of Personal Information Act 4 of 2013 (as amended):

  • All enhanced data management procedures maintain full POPIA compliance with strengthened security measures
  • Data collected through cloud systems will be stored on secure servers which may be hosted outside of South Africa with appropriate cross-border transfer protections
  • Only the research team will have access to participant data through enhanced authentication and authorization protocols
  • Data will continue to be anonymized using participant IDs with strengthened de-identification protocols
  • All cloud infrastructure changes enhance rather than compromise existing compliance standards
  • Enhanced participant rights protection through human subjects study classification requirements

Enhanced Infrastructure Summary

The following changes significantly enhance participant protection and data security:

  • Transition from UCT-only infrastructure to WHC-managed cloud infrastructure with AES-256 encryption
  • Implementation of 24/7 Security Operations Centre monitoring and advanced threat detection systems
  • Cloud-based computational resources with GPU acceleration for enhanced analytical capabilities
  • Automated backup and recovery systems with enhanced data integrity and disaster recovery
  • Cloud-specific access controls and automated compliance reporting for improved governance
  • Structured 5-phase migration approach with comprehensive risk mitigation during Year 5
  • Enhanced network security architecture with cloud-native firewall services

No changes to: Research methodology, participant recruitment, informed consent procedures, or data collection protocols. All changes enhance rather than modify existing data protection measures through improved technical infrastructure.

Risk Assessment and Mitigation

Comprehensive risk mitigation for cloud migration:

  • Structured 5-phase migration approach minimizes disruption and ensures data integrity during Year 5 transition
  • Enhanced security measures significantly improve threat detection and response capabilities
  • AES-256 encryption standard applied to both UCT servers and cloud storage systems
  • Automated backup and recovery systems provide enhanced data integrity and disaster recovery
  • Cloud-specific access controls and authentication protocols ensure secure data access
  • Regular security assessments and 24/7 monitoring throughout migration process
  • Comprehensive documentation and communication procedures for all stakeholders

Implementation Timeline: Cloud migration will be implemented following structured phases during Year 5 of the project, with complete migration of sensitive health data to WHC-managed cloud infrastructure by the end of Year 5. Implementation follows comprehensive planning, pilot testing, gradual migration, full migration, and optimization phases.

Final Confirmation

These amendments represent a comprehensive enhancement to the HE²AT Center Data Management Plan through cloud migration implementation during Year 5. The changes transition from Version 2.1 (UCT-only infrastructure) to Version 2.2 (WHC-managed cloud infrastructure) providing enhanced security, scalability, and operational efficiency. Key enhancements include AES-256 encryption standardization, 24/7 Security Operations Centre monitoring, cloud-based computational resources with GPU acceleration, automated backup and disaster recovery systems, and structured 5-phase migration strategy. All changes enhance rather than compromise participant protection measures through improved technical infrastructure. The cloud migration ensures transparent data governance whilst maintaining full POPIA compliance with enhanced security standards and improved operational capabilities through advanced cloud architecture and comprehensive risk mitigation frameworks.
