## Amendment Overview

This directory contains materials for **Amendment #2** to the HEAT001 protocol, focused on cloud migration infrastructure enhancements aligned with DMP v2.2.

### Amendment Focus
- Transition from UCT on-premise to WHC-managed cloud infrastructure
- Enhanced security measures (AES-256 encryption, 24/7 SOC monitoring)
- Improved data management capabilities
- Maintained POPIA compliance and ethical standards

## Key Amendment Changes

All changes are focused on **Section 5: Special Data Management Considerations**

### Modified Sections:
1. **Section 5.1 - Data types**
   - Added cloud storage infrastructure details
   - Updated data location references

2. **Section 5.3 - Data management, documentation and curation**
   - Enhanced backup and recovery systems
   - Cloud-native database services

3. **Section 5.4 - Data Security and Confidentiality**
   - AES-256 encryption for all data
   - 24/7 SOC monitoring
   - Multi-layered firewall protection
   - Enhanced access controls
   - New subsection: Enhanced Cloud Security Measures

4. **Section 5.5 - Procedure for making data available**
   - Enhanced DAC procedures
   - Additional legal review requirements
