Study Title: Innovative machine learning and multi-source data analysis towards development of an urban heat-health Early Warning System for African cities
Protocol number: HEAT002
Date of last version of protocol: 15 September 2023
HREC Reference No: 220606

Letter of Amendment #3 dated 01 October 2025

Overall rationale for the amendment

The HEAT002 study protocol requires updating to reflect the implementation of enhanced cloud infrastructure capabilities alongside existing UCT infrastructure. This strategic enhancement improves data security, computational capabilities, and research efficiency while maintaining all existing ethical standards and participant protections. The changes focus specifically on Section 5 (data analysis components) to incorporate WHC-managed cloud infrastructure with AES-256 encryption and 24/7 security monitoring. According to the rules of the Protection of Personal Information Act 4 of 2013 (as amended), data collected through cloud systems will be stored on secure servers which may be hosted outside of South Africa, with appropriate safeguards maintaining data protection standards.

Implementation of the protocol modification

Upon receiving research ethics committee approval for this protocol amendment, the site would implement the protocol amendment immediately. A copy of the protocol amendment approval along with any correspondence will be retained in the site's regulatory files of this study.

All proposed changes and their rationale

We have edited the text in Section 5 of the protocol, as described in the table below:

Location of Revision Description of Revision Reason for changes
Section 5.3, page 15
Previous text: Data management will be facilitated through the CSAG/UCT platform with standard backup procedures.
New text: Data management, documentation and curation will be facilitated through both the CSAG/UCT platform and WHC-managed cloud infrastructure with enhanced security, automated backup systems, and improved computational capabilities for complex data processing tasks.
 Implementation of enhanced cloud infrastructure to improve data security, automated backup capabilities, and computational resources while maintaining existing data management standards.

Previous text: Network security utilizes UCT's standard firewall protection.

 Implementation of multi-layered firewall protection and automated compliance monitoring provides enhanced network security and streamlined regulatory compliance oversight.

New text: Local authentication and authorization employs UCT's authentication protocols alongside cloud-based multi-factor authentication systems, role-based access controls with granular permissions, and automated access logging for enhanced security governance.

Summary of Enhancement Benefits:

  1. Enhanced data security through AES-256 encryption and 24/7 SOC monitoring
  2. Improved computational capabilities for complex machine learning analyses
  3. Enhanced disaster recovery and automated backup systems
  4. Streamlined compliance monitoring and governance oversight
  5. Maintained participant privacy protections and POPIA compliance

These targeted enhancements to Section 5 data analysis components ensure the HEAT002 study maintains the highest standards of data security and research efficiency while preserving all existing ethical protections and regulatory compliance requirements.
