**Letter of Amendment #3 dated 01 October 2025**

**Study Title:** Innovative machine learning and multi-source data analysis towards development of an urban heat-health Early Warning System for African cities

**Protocol number: HEAT002**

**Date of the last version of the protocol: 15 September 2023 (Version 2.0)**

**HREC Reference No: 220606**

**The overall rationale for the amendment**

The amendments to the protocol stem from the implementation of Version 2.2 of the HE²AT Center Data Management Plan, which introduces a structured transition from UCT on-premise infrastructure to WHC-managed cloud infrastructure during Year 5. This transition enhances data security, scalability, and operational efficiency whilst maintaining full POPIA compliance and all existing ethical standards.

**Implementation of the protocol modification**

Upon receiving the research ethics committee's approval for this protocol amendment, the site would implement the protocol amendment immediately following the structured 5-phase cloud migration approach detailed in the Data Management Plan. A copy of the protocol amendment approval and any correspondence will be retained in the site's regulatory files of this study.
