# HE²AT Center Data Management Plan Repository

## Main Documents (Ready to Share)

### **DMP v2.0.docx**
The official Data Management Plan Version 2.0 for the HE²AT Center. This is the primary document to share with stakeholders and submit for review.

### **DMP_v2.0_Track_Changes.docx**
Track changes version of the DMP v2.0 showing all modifications from previous versions. Use this for reviewing what has changed.

## Quick Access Guide

**To send the Data Management Plan:** Share **DMP v2.0.docx**

**To review changes:** Open **DMP_v2.0_Track_Changes.docx**

**To access protocol approvals:** Navigate to **Protocol_Approvals/** and select the relevant protocol (HEAT001 or HEAT002)

**To reference data types:** Open **Data Types.xlsx**
