## Amendment Overview

These v3.0 amendments focus on:
1. **Cloud Migration**: Transition from UCT on-premise infrastructure to WHC cloud platform
2. **Enhanced Security**: Implementation of AES-256 encryption and 24/7 SOC monitoring
3. **Data Governance**: Updated data sharing procedures and compliance frameworks
4. **Infrastructure Modernization**: Auto-scaling compute resources and automated backup systems

## Submission Process

1. **Review**: All amendment documents reviewed by DMAC PIs
2. **HREC Submission**: Submit via institutional HREC portal
3. **Tracking**: Monitor through HREC reference numbers (RP1: M220605, RP2: M220606)
4. **Implementation**: Phased cloud migration following HREC approval

## Compliance Notes

- All amendments maintain POPIA compliance requirements
- Cloud migration includes tripartite data transfer agreements
- Security assessments completed for WHC infrastructure
- Business continuity plans established for service transition
