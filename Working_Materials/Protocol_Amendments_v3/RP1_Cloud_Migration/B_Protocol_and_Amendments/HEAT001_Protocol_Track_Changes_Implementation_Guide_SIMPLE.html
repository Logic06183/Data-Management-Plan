HEAT001 Protocol Changes Implementation - Version 1.0 to 2.2

DMP Infrastructure Transition and Enhanced Security Measures

For Protocol Amendment #2 - Cloud Migration Implementation

Instructions for Implementation

This document provides exact text replacements for updating HEAT001 protocol from v1.0 to v2.2. Enable track changes in Word before making these replacements. Find each "Old text" section in your protocol and replace entirely with the corresponding "New text".

Section 5.1 - Data Management, Documentation and Curation
FIND AND REPLACE:
Old text: Data will be managed and curated using UCT CSAG servers with on-premise storage and Jupyter Hub platform for analysis.
New text: Data will be managed and curated using UCT CSAG servers with on-premise storage and Jupyter Hub platform for analysis, enhanced by WHC-managed cloud infrastructure capabilities during the transition period. The cloud infrastructure provides additional computational resources, automated backup systems, and enhanced security measures while maintaining compatibility with existing UCT systems.
Justification: To provide enhanced computational capabilities and improved data security through hybrid infrastructure approach during transition period while maintaining existing UCT capabilities.
Section 5.2 - Data Security and Confidentiality
FIND AND REPLACE:
Old text: Data security will be maintained through standard university security protocols and access controls.
New text: Data security will be maintained through standard university security protocols and access controls, supplemented by cloud infrastructure implementing AES-256 encryption for data at rest and in transit, 24/7 Security Operations Center (SOC) monitoring, automated threat detection systems, and enhanced disaster recovery capabilities. According to the rules of the Protection of Personal Information Act 4 of 2013 (as amended), data collected through cloud systems will be stored on secure servers which may be hosted outside of South Africa with appropriate safeguards.
Justification: To implement enhanced security measures exceeding minimum standards and ensure POPIA compliance for international data storage with appropriate safeguards.
Section 5.3 - Network Firewall and Virtual Private Network
FIND AND REPLACE:
Old text: Network security will be maintained through UCT institutional firewalls and VPN access controls.
New text: Network security will be maintained through UCT institutional firewalls and VPN access controls, complemented by cloud-based network security measures including distributed firewall protection, encrypted VPN tunnels, and network segmentation protocols that isolate research data from other network traffic.
Justification: To provide enhanced network security through multiple layers of protection and improved access management while maintaining existing UCT security infrastructure.
Section 5.4 - Local Authentication and Authorization
FIND AND REPLACE:
Old text: User authentication will be managed through UCT Active Directory and role-based access controls.
New text: User authentication will be managed through UCT Active Directory and role-based access controls, integrated with cloud-based authentication systems providing multi-factor authentication, single sign-on capabilities, and granular permission management. Only the research team will have access to this data through verified authentication protocols.
Justification: To strengthen user authentication and provide enhanced access control mechanisms while maintaining integration with existing UCT directory services.
Section 5.5 - Procedure for Making Data Available
FIND AND REPLACE:
Old text: Data will be made available to authorized researchers through UCT-managed access procedures following Data Access Committee approval.
New text: Data will be made available to authorized researchers through UCT-managed access procedures following Data Access Committee approval for all projects (internal consortium and external researchers). Enhanced cloud-based data sharing platforms provide secure data transfer, automated access logging, and real-time monitoring of data usage. Data will be anonymized using participant IDs and shared through encrypted channels with comprehensive audit trails.
Justification: To implement universal DAC review requirements and improve data sharing efficiency while maintaining security and providing enhanced monitoring capabilities with strengthened anonymization and audit procedures.
Section 5.6 - Data Analysis Platforms
FIND AND REPLACE:
Old text: Data analysis will be enabled through the CSAG/UCT Jupyter Hub platform.
New text: Data analysis will be enabled through the CSAG/UCT Jupyter Hub platform, enhanced with cloud-based computational resources providing auto-scaling capabilities, containerized analysis environments, GPU acceleration for complex analyses, and integrated backup and version control systems.
Justification: To provide enhanced computational capabilities for complex analyses while maintaining the existing Jupyter Hub platform that researchers are familiar with.
Section 5.7 - Data Storage and Archiving
FIND AND REPLACE:
Old text: Data will be stored on UCT CSAG servers with standard backup procedures.
New text: Data will be stored on UCT CSAG servers with standard backup procedures, supplemented by cloud storage infrastructure providing automated daily backups with 30-day retention, geo-redundant storage, and disaster recovery capabilities with AES-256 encryption at rest.
Justification: To provide enhanced data protection through redundant storage systems and improved disaster recovery capabilities while maintaining existing UCT storage systems.
Section 5.8 - Data Governance and Compliance
FIND AND REPLACE:
Old text: Data governance will follow UCT policies and applicable South African regulations.
New text: Data governance will follow UCT policies and applicable South African regulations, enhanced by automated compliance reporting systems, real-time monitoring of data access patterns, and comprehensive audit trails. All cloud infrastructure maintains compliance with POPIA requirements and international data protection standards.
Justification: To strengthen compliance monitoring and provide enhanced governance capabilities during the transition period.

Protocol Amendment Implementation

Upon receiving research ethics committee approval for this protocol amendment, the site will implement the protocol modifications in a phased approach over twelve months during Year 5 of the project, ensuring continuity of existing operations while gradually introducing enhanced capabilities. This represents a temporary transition period with the goal of complete cloud migration by the end of Year 5.

A copy of the protocol amendment approval along with any correspondence will be retained in the site regulatory files for this study. All enhanced security measures and compliance protocols will be operational from the beginning of the transition period.

Key Implementation Points:

  • Maintains all existing UCT infrastructure and capabilities
  • Adds enhanced cloud-based security and computational resources
  • Implements universal DAC review for equitable data access
  • Strengthens POPIA compliance for international data storage
  • Provides enhanced disaster recovery and backup capabilities
  • Enables advanced computational analyses with GPU acceleration
