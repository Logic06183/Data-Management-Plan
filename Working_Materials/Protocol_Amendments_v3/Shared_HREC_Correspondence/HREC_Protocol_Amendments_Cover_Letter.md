# Cover Letter for Protocol Amendments
## HE²AT Center Cloud Migration Infrastructure Updates

**Date:** 01 October 2025

**To:** Wits Human Research Ethics Committee (HREC)

**From:** HE²AT Center Principal Investigators

**Re:** Protocol Amendments for HEAT001 (RP1) and HEAT002 (RP2) - Cloud Migration Infrastructure Updates

---

## Executive Summary

We respectfully submit protocol amendments for both HEAT001 (RP1 - Reference No: 220605) and HEAT002 (RP2 - Reference No: 220606) to reflect critical infrastructure enhancements detailed in Version 2.2 of the HE²AT Center Data Management Plan.

## Background and Rationale

The HE²AT Center is implementing a strategic transition from UCT on-premise infrastructure to WHC-managed cloud infrastructure during Year 5 (2025-2026). This transition enhances data security, scalability, and operational efficiency whilst maintaining full POPIA compliance and exceeding existing ethical standards.

## Key Infrastructure Enhancements

### Enhanced Security Measures
- **AES-256 Encryption:** All data at rest and in transit
- **24/7 SOC Monitoring:** Continuous security monitoring and threat detection
- **Multi-layered Firewall Protection:** UCT Cisco firewall plus cloud-native firewall services
- **Role-based Access Controls:** Multi-factor authentication and granular permissions

### Improved Data Management Capabilities
- **Automated Backup Systems:** Enhanced disaster recovery capabilities
- **Cloud-native Database Services:** Improved data integrity monitoring
- **Enhanced Computational Resources:** GPU acceleration for complex analyses
- **Automated Compliance Reporting:** Streamlined governance oversight

### Maintained Compliance Standards
- **POPIA Compliance:** All existing data protection standards maintained or enhanced
- **Ethics Standards:** No changes to participant consent or data use scope
- **DAC Oversight:** Enhanced procedures for comprehensive data access governance
- **Legal Review:** Additional UCT/WHC legal counsel review for institutional compliance

## Scope of Protocol Changes

Both protocol amendments focus exclusively on **Section 5 (Special Data Management Considerations)** and related subsections, specifically:

1. **Data Storage Infrastructure** - Hybrid UCT/cloud environment description
2. **Data Security and Confidentiality** - Enhanced security measures documentation
3. **Data Access Procedures** - Improved DAC governance with legal review
4. **Network Security** - Updated firewall and monitoring capabilities

## Critical Clarifications

### No Changes to Research Scope
- **Participant consent scope remains unchanged**
- **Data collection procedures remain unchanged**
- **Analysis objectives remain unchanged**
- **Ethical frameworks remain unchanged**

### Enhanced Protections Only
- **All changes represent security and infrastructure enhancements**
- **No reduction in data protection standards**
- **Maintained or improved participant privacy protections**
- **Enhanced compliance monitoring capabilities**

## Implementation Timeline

The cloud migration follows a structured 5-phase approach:
1. **Planning and Assessment** (Months 1-2)
2. **Pilot Implementation** (Months 3-4)
3. **Gradual Migration** (Months 5-7)
4. **Full Migration** (Months 8-9)
5. **Optimization** (Months 10-12)

Implementation will commence immediately upon HREC approval of these amendments.
